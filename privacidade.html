Política de privacidade do Nexo

Última atualização: 18 de outubro de 2026.

O Nexo é um assistente pessoal de uso privado. O único usuário é o próprio desenvolvedor, que autoriza o acesso à sua conta Google.

Dados acessados

  • Google Agenda: leitura de eventos e de disponibilidade das agendas do próprio usuário, e criação de eventos somente depois de aprovação explícita.
  • Gmail: leitura (somente leitura). O Nexo não envia, não apaga e não altera e-mails.

Como os dados são usados

Os dados são processados no computador do próprio usuário para organizar a agenda, as pendências e as anotações pessoais dele. Trechos podem ser enviados à API da Anthropic (Claude) para gerar resumos e respostas ao próprio usuário. Os dados não são vendidos, compartilhados com terceiros nem usados para publicidade.

Armazenamento e revogação

Os tokens de acesso ficam apenas no computador do usuário, com acesso restrito. O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

O uso de informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Nexo is a private, single-user assistant. Google Calendar and Gmail (read-only) data are processed on the owner's computer for the owner's own use, may be sent to the Anthropic API to generate replies to the owner, and are never sold or shared. Use of Google API data complies with the Google API Services User Data Policy, including the Limited Use requirements.
